### 新增功能
- 重复参数黄字提醒：一键传参粘贴的命令行中若同一参数出现多次（含 `-c` 与 `--ctx-size` 这类别名），解析预览会黄字列出重复参数并标黄对应行；高级参数卡片中与其他生效参数重复的条目，名称旁也会显示黄字提醒徽章。只提醒不拦截，不阻止保存与启动。
- 日志窗口支持放大：工具栏新增放大按钮，日志面板可展开为覆盖主区域的浮层，按 ESC 或点还原按钮恢复原位。
- 原始参数编辑态的标题与「复原」「完成」按钮吸顶：长参数列表滚动到顶部时操作按钮不再滚出视野。

### 功能优化
- 无

### Bug 修复
- 模型加载期间现在可以中途停止服务：此前启动后最长要等约 90 秒加载完成才能点停止。
- 大模型慢加载不再误报「启动较慢」：超过等待时长会自动转入后台监控，就绪后状态自动更新为运行中。
- 启动失败提示透传具体原因（如端口占用、路径不存在），不再一律笼统显示「启动失败」。

> 详细改动参考 CHANGELOG
