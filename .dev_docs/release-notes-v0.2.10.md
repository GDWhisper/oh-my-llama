### 功能优化
- **设置浮窗改两列摆放**：
  - 弹窗加宽，设置分组按语义分左右两列：语言 / 主题 / 更新与代理在左列，关闭偏好 / 开机自启 / 任务栏小窗 / 关于在右列，总高度明显压平、少滚动
  - 窗口窄到放不下两列时自动整体换行回落单列，无需按断点单独适配

### Bug 修复
- **任务栏小窗休眠唤醒后整应用卡死**：
  - 现象：电脑休眠唤醒后，整个应用无响应、托盘图标点击无反应，只能强行结束进程
  - 根因：小窗定位线程每秒直接调用窗口接口，与主线程的窗口消息处理跨线程反向争抢同一把锁，两线程互等形成死锁
  - 修复：每拍核对改为排队到主线程串行执行；先算好本拍动作再执行，窗口操作与状态记账不再交叉持锁；另加可重入守卫，窗口操作同步回调导致二次进入时直接挡掉
