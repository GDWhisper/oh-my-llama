本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 关闭窗口可最小化到系统托盘：托盘图标左键单击恢复窗口、右键菜单「显示 / 退出」；首次关闭窗口时弹窗询问，可勾选「记住选择」，之后也可在设置中随时更改。最小化到托盘不影响正在运行的服务，退出前会先停止服务。
- llama-server 路径输入框升级为「输入 + 候选」组合框：聚焦即列出最近启动成功过的路径与各配置中已填写的路径，无需反复翻目录挑选可执行文件。
- 配置命名弹窗新增「填入模型名称」按钮：一键将所选模型文件名回填为配置名（自动去掉目录与 .gguf 后缀）。
- 更新弹窗现在展示新版本的更新说明，并提供「在 GitHub 查看完整说明」链接。

### 功能优化
- 轻量提示（toast）可点击 × 立即关闭，鼠标悬停暂停倒计时，底部进度条直观显示剩余时间。
- 设置面板改为分组卡片式布局，选项整行可点、图标辅助扫读。
- 开启自动检查更新后，对已点「以后再说」的版本不再重复提醒，直到出现更高版本。

### Bug 修复
- 修复手动点击「检查更新」被误判为自动检查的问题：此前无更新时没有任何反馈、发现更新也不弹窗；现已恢复正常弹窗与「已是最新」提示。
