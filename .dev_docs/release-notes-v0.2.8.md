### 新增功能
- **度量面板解析草稿接受率（官方投机解码 / MTP）**：
  - 运行官方 llama.cpp 投机解码（含 MTP draft-mtp）时，性能面板新增「草稿接受率」指标，显示接受率与「接受数/验证数 · 均长」小字。
  - 未开启投机解码时无数据，整行不渲染、不显示 0% 占位。

### 功能优化
- 无

### Bug 修复
- **运行中改端口 / 换配置不再误报「已停止」**：
  - 「运行中」判定改为以服务 `GET /health` 返回 200 为准（模型已加载、可服务），不再依赖裸端口连通。
  - 运行中切换端口 / 地址、或被本应用接管外部服务时，不再错误提示「llama-server 已停止」或误挂「外部服务」徽章。
- **一键传参正确识别 PowerShell 多行命令**：
  - 粘贴含 PowerShell 行尾反引号（续接符）的多行命令，不再把反引号灌入自定义参数，也不会粘在前一个参数上污染取值。
  - 无 `-m` 的模型文件路径现在正确归位到模型字段并推导模型目录；存量脏配置重新粘贴一次干净命令即自动覆盖。

> 详细改动参考 CHANGELOG
