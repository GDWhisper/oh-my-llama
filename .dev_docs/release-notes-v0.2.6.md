### 功能优化
- **系统性能面板改版**：推理速度（预处理 / 生成）由行内「最近 · 平均」改为卡片式展示——大字显示「估计」（会话下限包络拟合速度，对并发 / 卡顿 / 降频等只变慢的噪声稳健），小字保留单次真实读数「最近」（卡片够宽时贴右下角，放不下自动折行）；GPU 功耗由纯数值改为带填充比例的占用条（以功率上限为基准，取不到上限时回退数值）；CPU 行新增型号显示（i5-13600K / Ultra 7 265K / Ryzen 7 5800X 等，取不到不显示）；累计请求数独立成行。

### Bug 修复
- **推理速度读数系统性偏低**：原「平均」按 Σtokens / Σ时间 计算，被每批固定开销（小样本）与多 slot 并发重叠墙钟（同一时段算两遍）拉低，实测预处理被报 48 t/s 而真实约 1700。改为不丢任何样本的下限包络拟合估计（只变慢的噪声不污染结果），「最近」仍为单次真实读数；对应 i18n `metrics.avg` 更名 `metrics.est`（估计）。
