本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 日志面板改为按需展开：默认只渲染最近 800 行输出，顶部出现「加载更早日志」按钮，可逐批向上翻阅更早的历史内容。

### 功能优化
- 大幅降低 CPU 占用：日志改为批量刷新、服务空闲时完全停止状态轮询、窗口隐藏或常驻托盘时轮询降频；后端的进程存活探测改为单点增量刷新，且不再阻塞状态锁。模型加载期高频刷日志、以及长时间挂后台时的开销明显下降，「启动 / 停止 / 打开预览」不会再被状态探测排队拖住。
- 设置浮窗整合：版本信息、检查更新、自动检查与更新代理合并为一张「更新」卡片；「关于」卡片改为应用简介与仓库入口。

### Bug 修复
- 端口被外部服务占用时（例如自己在终端启动的 llama-server，或其他恰好占用该端口的程序），状态徽章不再把它误标成本应用的「运行中」，改为显示「外部服务」并在地址行提示占用情况，同时禁用「打开预览」，避免状态显示与按钮可操作性互相矛盾。
- 修复关闭窗口弹窗选择「直接退出」后应用没有反应的问题：此前该路径会在停止服务的过程中异常中断，既不退出也无提示；现已正常停服并退出。
