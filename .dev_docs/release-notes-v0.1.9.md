本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 模型目录输入框现在会记住本机用过的目录（与 llama-server 路径输入框同款机制）：输入时给出「最近用过 + 各命名配置里的目录」候选，点击即回填，也可从历史中移除单条；启动过服务后新目录自动进入候选。
- 切换配置的下拉框支持输入搜索过滤，与「选择模型」同款交互：按名称（含默认配置的展示文案）即时筛选，无匹配时给出提示。

### 功能优化
- 首次启动的语言不再固定为中文：未手动设置过语言时，界面跟随系统语言（系统为中文则显示中文，否则显示 English）；已手动切换过的用户不受影响。
