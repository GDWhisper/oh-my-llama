本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 性能卡片新增推理速度指标：预处理与生成的「最近一次 + 平均」速度、累计请求数，随服务启停自动清零。
- 运行日志落盘：llama-server 运行日志自动写入本地日志目录（滚动保留 20 份），日志面板新增「日志文件」按钮一键打开。
- 高级参数中的多模态投影文件（--mmproj）与聊天模板文件（--chat-template-file）支持文件选择器，可浏览选择而非纯手输。

### 功能优化
- 性能卡片显卡型号并入 GPU 行显示，收起态摘要直接可见推理速度。
- 文件浏览的默认起始目录更贴心：聊天模板从 llama-server 所在目录打开，mmproj 从已设置的模型目录打开。

### Bug 修复
- 上下文长度输入清空后保持空白，不再自动补 0。
- 启动失败提示改用与其他操作一致的轻量 Toast，不再打断操作。
