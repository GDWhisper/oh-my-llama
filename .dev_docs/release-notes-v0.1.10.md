本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 日志面板新增时间显隐开关，可按需隐藏/显示每行前的时间戳，隐藏后日志正文铺满整行；设置在重启后保留。
- llama-server 路径与模型目录输入框新增「打开」按钮，一键在系统文件管理器中定位所选文件或目录。

### 功能优化
- 搜索型下拉（选择模型、选择配置）展开时自动滚动定位到当前选中项，长列表中无需手动寻找。
- 「浏览」按钮文案去掉省略号，与「打开」按钮视觉更一致。

### Bug 修复
- 修复日志时间戳与本地时间相差 8 小时的问题（此前按 UTC 显示）。
