### 新增功能
- **任务栏常驻系统性能小窗（仅 Windows）**：
  - 设置新增「任务栏性能显示」卡片：一个总开关 + CPU / 内存 / GPU / 显存四项勾选，按勾选顺序从左到右显示，全部取消勾选即自动关闭
  - 无边框、置顶、点击穿透、不抢焦点的条带贴在托盘区左侧（竖向任务栏贴托盘上方）；跟随系统 DPI，任务栏自动隐藏或前台全屏时自动收起，资源管理器重启后自行复位
  - 样式可选「默认（深色底）」或「透明（与任务栏融合）」：透明样式无底色，文字直接叠在任务栏上，按任务栏日间/夜间自动取色并加描边，开亚克力或透出壁纸时细笔画不糊
  - 排列可选「单行」或「两行」（每行两项，占用更少的任务栏横向空间；竖向任务栏自动按单行处理）
  - 可勾选「显示具体数据」：内存 / 显存在百分比后追加「已用/总量 GB」（如 22.1/32.0G）
  - 非 Windows 平台该卡片整卡不显示

### 功能优化
- **设置浮窗滚动条并入统一风格**：设置浮窗正文的滚动条与主界面左右两栏一致（细、低对比、悬停略加深），不再走系统默认粗滚动条
- **性能采集去重**：主面板与任务栏小窗同为 1.5 秒轮询且错峰发起，现在 1 秒窗口内复用同一份快照，错峰的那一次不再重复采集（逐卡 GPU 查询是采集里最贵的一段），常驻开销进一步下降
