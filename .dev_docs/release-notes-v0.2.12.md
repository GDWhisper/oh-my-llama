### 新增功能
- **托盘菜单「性能监控」开关**：
  - 右键点击托盘图标，菜单里直接勾选或取消「性能监控」，即可打开或关闭任务栏性能小窗，不用先打开设置面板
  - 勾选态与设置面板「任务栏性能显示」卡片是同一个开关：托盘改了，设置面板同步显示；设置面板改了，托盘勾选态同步
  - 再次打开时沿用上次选择的监控项；若此前把所有监控项都取消过，重开时恢复默认四项
  - 仅 Windows 提供（任务栏小窗本身仅支持 Windows）
