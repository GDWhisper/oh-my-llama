### 新增功能
- **托盘菜单「性能监控」开关**：
  - 右键点击托盘图标，菜单里直接勾选或取消「性能监控」，即可打开或关闭任务栏性能小窗，不用先打开设置面板
  - 勾选态与设置面板「任务栏性能显示」卡片是同一个开关：托盘改了，设置面板同步显示；设置面板改了，托盘勾选态同步
  - 再次打开时沿用上次选择的监控项；若此前把所有监控项都取消过，重开时恢复默认四项
  - 仅 Windows 提供（任务栏小窗本身仅支持 Windows）
- **「启动设置」卡片新增「启动时隐藏到托盘」选项**：
  - 设置面板原「开机自启」卡片改名「启动设置」，卡内新增「启动时隐藏到托盘」复选项（默认关闭）
  - 开启后应用启动时直接隐藏主窗口，只在系统托盘留图标，不在任务栏露面
  - 适合配合开机自启使用：开机后不抢屏幕焦点，需要时从托盘打开主窗口
  - 开机自启开关仍仅 Windows 显示；「启动时隐藏到托盘」各平台可用
