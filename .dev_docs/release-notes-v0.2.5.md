本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- 开机自启：设置页新增「开机时自动启动」开关（默认关闭），登录系统后自动运行本应用；便携版移动目录后自启条目会自动指向新位置。

### 功能优化
- 降低后台资源占用：窗口隐藏到托盘或最小化时停止系统指标轮询（此前该降频逻辑从未生效，最小化后空闲仍持续占用 CPU）；收起性能面板时降频至 3 秒；数值无实质变化时不触发重渲染。空闲场景 CPU 占用与界面开销均明显下降。

### Bug 修复
- 修正 29 处伪类选择器误写的空格（如 `: hover`），这些规则此前被浏览器整条忽略，导致部分悬停 / 禁用 / 聚焦样式不生效。
- 缩略图预览头部图标进一步按系统小图标尺寸精确渲染，修掉上一版仍残留的发虚。
