本版本亮点由发布 agent 基于 CHANGELOG 手动总结。详细条目见 CHANGELOG.md。

### 新增功能
- **上下文长度快捷预设标签（8K–256K）**：
  - 上下文长度输入框下方新增一排预设：8K / 64K / 96K / 128K / 200K / 256K
  - 点击即填入对应 token 数，免去手动换算

- **度量面板支持 KVMem fork 日志**：
  - 解析 KVMem fork 的 KVMEM_* 日志，提取预处理等待与缓存命中率
  - 预处理速度卡片小字改用「本轮等待 + 命中率」展示（该 fork 单看 t/s 会失真）

### 功能优化
- **读写超时改为可选参数**：
  - 移除启动器强制注入的 `--timeout 2400`，默认回落 llama-server 600s
  - 超时改由「读写超时」结构化参数卡片统一控制（粘贴命令中的超时自动识别为可编辑项）

### Bug 修复
- **推理速度卡片小字折行修复**：
  - 两卡小字改为同排贴右、放不下时两张一起折行并右对齐，行高对齐不再抖动

> 详细改动参考 CHANGELOG
