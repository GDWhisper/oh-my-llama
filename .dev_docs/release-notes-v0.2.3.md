### 新增功能
- 自定义标题栏与暖纸米色主题：窗口改用无边框自定义标题栏（品牌标识、最小化 / 最大化 / 关闭），主界面整体切换为暖纸色板，日志终端保持深色。
- 系统性能面板占用条：CPU、内存、GPU 利用率与显存改为横向占用条展示，高占用自动高亮，细节信息更清晰。

### 功能优化
- 主窗口默认宽度微调，性能面板与右侧卡片栅格对齐，观感更整齐。
